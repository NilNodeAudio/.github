## 🎛 What is NilNode Audio?

An open ecosystem of **tiny, free audio tools** for the whole production chain —
recording, processing, mixing, mastering and SFX design. Every tool is a bunch of
static files: open `index.html` in any browser and it just works. **No installs,
no accounts, no cloud, no internet required.** Under the hood — pure
**Web Audio API**: nodes, graphs and zero bytes of baggage.

> 🎹 **Liminal Instruments** — our synth line lives here too:
> [github.com/effdst/LiminalInstruments](https://github.com/effdst/LiminalInstruments)

## 🧩 The ecosystem

| Tool | What it does | Runs | Status |
|---|---|---|:---:|
| **NilNode Recorder** | multitrack capture from mic / system audio | browser · portable | 🟢 live |
| **NilNode SFX Forge** | procedural sound-effect generator | browser · portable | 🟢 live |
| **NilNode Master** | mix bus: analyzer, EQ, limiter, loudness | browser · portable | 🟡 wip |
| **Liminal Instruments** | web synthesizers & instruments | browser · portable | 🟢 live |

<details>
<summary>📦 Portable / offline usage</summary>

Every repo is self-contained: download the ZIP (or `git clone`), unzip anywhere —
a USB stick counts — and open `index.html`. Apps cache themselves in the browser
and keep working with the network cable unplugged.

</details>

## ⚡ Quick start

1. ☁️ **Web** — open any tool from the table above, straight from GitHub Pages.
2. 💾 **Portable** — download a repo ZIP → unzip → open `index.html`. Done.
3. 🧰 **Hack it** — static JS + Web Audio API, no build step, no dependencies.
   Fork, edit, reload.
